# Сайт ulpia.bg

Публичният сайт на Улпия Дивелъпмънт (кв. Коматево, Пловдив).

- `site/` – всичко, което се качва на ulpia.bg
- Наличността и запитванията идват от приложението Улпия (Supabase): функции `site_availability` и `site_inquiry` – без цени и без лични данни на клиенти.
- Всяка промяна в `main` се качва автоматично по FTP в SuperHosting (`.github/workflows/deploy.yml`, тайни FTP_SERVER / FTP_USERNAME / FTP_PASSWORD).
- Статистика: Google Analytics G-TQFCB4MT7L и Microsoft Clarity zdijdq4gs0, включват се само след съгласие за бисквитки.
